# * Splunk Server Deployment
Installing and configuring the Splunk Server to collect, index, and analyze security logs from connected endpoints.
The server provides centralized log monitoring and helps detect suspicious activity through searches, alerts, and dashboards.

------------------------------------------------------------------------------------------------------------------------
## Step-by-Step Guide: Splunk Server Deployment

### Step 1:- 
Go to Splunk Web Console, Click on Trials & Downloads.

<img width="1910" height="943" alt="Screenshot 2026-08-14 173317" src="https://github.com/user-attachments/assets/04c2c073-94cb-4ed0-be1e-d3fb7fa94a16" />

There, you will see the Splunk Enterprise interface.

<img width="1912" height="952" alt="Screenshot 2026-08-14 173404" src="https://github.com/user-attachments/assets/86cd852d-fb76-405d-bad5-c214876e59b3" />

Register for a Splunk account and then log in using your Passkey.

<img width="1919" height="835" alt="Screenshot 2026-08-14 173438" src="https://github.com/user-attachments/assets/35240c42-ed59-48b6-a412-23f4e5ee50bb" />

Then, select the operating system where you want to install Splunk Enterprise.

<img width="1919" height="818" alt="Screenshot 2026-08-14 173457" src="https://github.com/user-attachments/assets/f843361e-914a-414f-a449-3195461d9552" />

### Step 3:-
Once the download is complete, open the installer and start the installation process, there you create Admin Account.

<img width="508" height="400" alt="WhatsApp Image 2026-08-14 at 20 07 31" src="https://github.com/user-attachments/assets/d3f3eebd-b069-4cb6-bce7-b7df456597e5" />


The installation will now begin. Wait for the installation to finish. Once completed, Splunk will open in your web browser, where you can access the Splunk Dashboard.

<img width="600" height="412" alt="WhatsApp Image 2026-08-14 at 20 07 31 (6)" src="https://github.com/user-attachments/assets/14e8f42d-4fb5-4787-9bac-e892bf5c81cb" />

The Splunk login page will open like this. Enter the username and password you created during the installation.

<img width="1911" height="863" alt="Screenshot 2026-08-14 201303" src="https://github.com/user-attachments/assets/7be97451-62ef-4f43-8a27-aade37443ecb" />

After logging in, your Splunk Dashboard will be ready to use.
